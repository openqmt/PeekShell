# 感恩回馈

感谢每一位支持 PeekShell 的朋友。赞助不仅帮助项目持续维护与迭代，也会为你开通更多使用权限。

## 可开通权限

赞助后，可按赞助情况开通或解锁更多能力，例如：

- **终端 AI**：在终端场景中使用 AI 助手，获得命令建议与排障辅助
- **更换背景**：自定义应用外观与终端背景，打造更舒适的工作环境
- **云端同步**：跨设备同步主机、配置等数据，减少重复设置

后续还会根据社区反馈逐步开放更多回馈能力。

## 如何开通

完成资金赞助后，可通过 [GitHub Issues](https://github.com/openqmt/PeekShell/issues) 或与维护者联系，说明赞助信息与希望开通的权限，我们会协助完成开通。

再次感谢你的支持，让 PeekShell 走得更远。
